Collapsed by default into a corner button; expanded panel shows mini-SVG samples that reuse the real classes so colours stay in sync with the actual rendering. pointer-events: auto on inner buttons; the wrapper is pointer-events: none so it doesn't intercept pan/zoom gestures on the viz stage behind it. #}

Shapes

  • rect — operation / action
  • diamond — decision / branch
  • parallelogram — I/O boundary
  • hexagon — pre-existing referenced module
  • diverged — same site, today vs. proposed behaviour split
  • struct — named-field data shape kinds: struct, union, collections

Change markers (side)

  • shared — unchanged (context)
  • proposed — new in this change
  • existing — present today, going away (dashed)
  • diverged — same site, in-place semantic shift

Cross-flow lines (kind)

  • data — values flowing between steps
  • control — control flow / invocation
  • schema — shape definition reference
  • queue — message-bus traversal
  • utility — shared infra / helper
  • observability — tracing / metrics

Focus states

  • focused — click-selected step
  • predecessor / successor — directly connected to focused
  • faded — outside the focus cluster
