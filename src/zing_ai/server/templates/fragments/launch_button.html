{# launch_button.html — canonical launch button macro. Usage: {% from "fragments/launch_button.html" import launch_button %} {{ launch_button(card, label="PR Audit", slot="pr-42", skill="pr-audit", pr_number=42) }} The button posts to /command-center/launch-background with the appropriate payload, indicates "Launching…" while a launch is in flight, and pairs with per-card busyButtons signal pre-init in kanban_card.html. The DOM id uses the raw ``card.key`` (which may contain hyphens) followed by the slot.
