{# ── Launch Popup ──────────────────────────────────────────────────────────── Live terminal iframe (a per-session ttyd loopback URL) plus a primary "Send to Flow ▸" button. The iframe lifecycle is owned by the openLaunchPopup / closeLaunchPopup functions in cc-modals.js, which mirror the openTerminal / close-terminal pattern. Signals consumed (all pre-declared in _build_initial_signals): $modals.launchPopup — boolean; true = visible $launchPopupSession — tmux session name (e.g. "zing-bak-1") $launchPopupUrl — http://127.0.0.1:/ iframe src $launchPopupTitle — human-readable session title ── #} {# Heartbeat / wake-up: gated by $modals.launchPopup so the timers tick silently while the popup is closed and only POST while it's visible. $launchPopupSession is the tmux session name (set by /flow/launch-popup-open). #}
