Prototype N: Configurable Primary + Rich Kebab

User picks their preferred primary action; kebab menus include search + shortcuts

Builds on F with two additions:

1. Configurable primary actions: The visible primary button on each strip type (PR, session) can be changed by the user in settings. For example, some users might prefer "Start locally" over "Review" as their PR action. The kebab marks the current default with a small label, and any item in the kebab can be set as the new default.

2. Rich kebab menus: The kebab dropdown includes a search bar (from K), keyboard shortcuts, and brief descriptions. This combines the discoverability of the command palette with the per-item targeting of F.
