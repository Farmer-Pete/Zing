Prototype I: Hover Toolbar

Floating dark toolbar appears above the card on hover

Concept: The card body is purely informational — no action buttons anywhere inside. When hovering over the card, a dark floating toolbar slides down from above the card (like VS Code's peek toolbar or GitHub's PR hover actions). Actions are grouped by type with subtle dividers.

Key benefit: Zero button clutter on the card. All actions in one consistent location regardless of card state. The dark navy background makes it visually distinct from card content — no confusion about what's info vs. what's actionable.

Trade-off: Hover-dependent UI doesn't work on touch. Toolbar can collide with cards above in tight column layouts. Need to handle the case where multiple toolbars would stack.
