Prototype P: Best Of

F's per-item pattern + N's rich kebab + O's contextual awareness

This combines the winning elements from all prototypes:

from F Per-item actions — each PR and session strip gets its own primary button + kebab. Actions are scoped to the specific item.

from N Rich kebab menus — PR kebabs include search bar + keyboard shortcuts for power users. Session kebabs stay compact (fewer options).

from O Contextual primary — the primary button label changes based on state (Review for open PRs, Respond when changes requested, Attach for running sessions, Resume for stopped).

from K Keyboard shortcuts — shown in menus for fast access without clicking.

Rules: Strips with only 1-2 possible actions skip the search bar. Merged/completed PRs only get a kebab (no primary). Footer only appears for ticket-only cards.
