Prototype S: Dual Button (Launch / Copy)

Each menu item has an explicit copy button on the right side

Concept: Each menu row is split into two zones:

• Left side (main area) → click to launch the action
• Right side (clipboard icon) → click to copy the CLI command

The copy column has a small header label and a subtle clipboard icon per row. Link-only items (Open on GitHub, Open in Linear) span the full width since they have no CLI equivalent.

Trade-off: More explicit than right-click — every action visibly shows it can be copied. But the menu is slightly wider and the two-column layout adds visual complexity. Works well on touch devices where right-click isn't available.
