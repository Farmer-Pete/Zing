Prototype K: Command Palette

Searchable action palette scoped to the selected card

Concept: Each card has a subtle trigger button (or press / while hovering). This opens a command palette — a VS Code/Raycast-style overlay — scoped to that card's available actions. Actions are searchable by name.

Key benefit: Unlimited actions without any card clutter. Fuzzy search means power users can invoke any action in 2-3 keystrokes. The palette can include descriptions explaining what each action does.

Trade-off: Heavier interaction pattern — the palette is a modal. Might be overkill for simple cards with only 2-3 actions. Requires good keyboard navigation to feel native.
