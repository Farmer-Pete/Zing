Prototype J: Right-Click Context Menu

Zero visible buttons. All actions via right-click.

Concept: The card shows absolutely no action buttons. Right-clicking (or Ctrl-clicking) anywhere on the card opens a custom context menu with all available actions, grouped by category. The primary action is highlighted at the top.

Key benefit: Maximum information density. Cards are as compact as possible. Keyboard shortcuts provide power-user acceleration. The context menu is unlimited in size — it can hold every possible action without cluttering the card.

Trade-off: Poor discoverability — new users won't know to right-click. Must provide an alternative trigger (maybe clicking a subtle dot in the corner). Not mobile-friendly. Right-click conflicts with browser dev tools.
