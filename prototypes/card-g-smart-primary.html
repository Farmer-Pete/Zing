Prototype G: Smart Primary Action

Card state determines the ONE action you most likely want

Concept: The card computes its most likely next action based on state signals and shows it as a single prominent button in the action bar. A ↓ chevron expands a drawer with all other actions, organized by category.

State machine: Changes requested → "Respond". Needs review → "Review". Running session → "Attach". To Do → "Start ticket". In Progress (no PR) → "Plan ticket". Approved → "Merge".

Trade-off: The "right" primary action is a guess. Sometimes you want the second-most-likely action, which now costs an extra click. But for the common case, it's faster.
