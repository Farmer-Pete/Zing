Prototype F: Overflow Menu

One visible primary action + kebab menu per strip

Concept: Each strip (PR row, session row) shows at most one primary action button (the most likely thing you want to do) plus a kebab menu (⋮) that contains all other actions. This keeps the visual clutter to exactly 2 elements per strip while preserving full functionality.

Primary action heuristic: PR strip → "Review". Session strip (alive) → "Attach". Session strip (dead) → "Resume". Footer → "Plan Ticket" or "Start".

Trade-off: Adds one click for secondary actions. But the kebab is a universally understood pattern (GitHub, Jira, Slack all use it).
