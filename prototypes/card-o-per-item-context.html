Prototype O: Per-Item Right-Click Context

Primary button per item + right-click context menu per item (no kebab)

Concept: Like F but replaces the kebab with right-click context menus. Each strip (PR, session) shows only its primary action button. Right-clicking a specific strip opens a context menu scoped to that strip's item — right-click a PR strip to get PR actions, right-click a session strip to get session actions.

Key insight from J feedback: One right-click per card isn't enough. This solves that — the context menu is per strip, so right-clicking the PR row gives PR actions and right-clicking the session row gives session actions. The card body itself is cleaner because there's no kebab icon.

Trade-off: Same discoverability issue as J — new users won't know to right-click strips. A subtle hint ("right-click for more") appears on hover. Could combine with kebab as a fallback.
