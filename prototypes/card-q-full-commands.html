Prototype Q: Full Zing Command Coverage

N's configurable defaults + P's contextual awareness + every zing command mapped

What's new: Every /zing skill is mapped to a specific card location. PR strips offer three review types (code audit, PR review with line comments, visual/browser review). Ticket footers expose plan/build/audit commands contextually. The config panel includes all defaults. Search bar appears in PR kebab menus (5+ items); session kebabs stay compact.
