## In a plan
Find, and propose deletion for each:
- An abstraction with one caller.
- An interface with one implementation.
- A pattern introduced before three repetitions.
- Anything the working demo and the goals do not need.
- A dependency where the standard library would do.

Find each task that adds three or more new functions with their tests,
and propose splitting it so each part fits one build run.
