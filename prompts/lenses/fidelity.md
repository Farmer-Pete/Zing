## In a plan
Check that the plan covers the ticket and every scenario, and that
nothing in the plan exceeds the ticket.

## In code
Check the diff against the plan task by task. A deletion the plan did not
list is a blocker. Quote the plan element for every finding.
When the inputs include the accepted perimeter files input, each line names a path outside the plan's files that the owner accepted at a perimeter question, with the question key and the builder's reason. A listed path counts as in plan. A listed path is not a fidelity finding.
