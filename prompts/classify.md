Decide whether this ticket is a bug or a feature.

A bug is a report that something that exists behaves wrongly: a crash, a
wrong result, a regression, a failure the reporter can trigger. A feature is
everything else: new behavior, a change to intended behavior, a refactor, a
chore.

Read the ticket. If the words alone do not settle it, read the code the
ticket names and settle it from what the code does today.

Done when you can state the kind and the one fact that decided it.
